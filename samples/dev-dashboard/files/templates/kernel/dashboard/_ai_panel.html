Turn on the assistant

Bring your own provider and key. Set these in .env and restart the server:

DASHBOARD_AI_PROVIDER=anthropic
DASHBOARD_AI_API_KEY=…
# DASHBOARD_AI_MODEL=claude-sonnet-5-5   (or claude-opus-5-5, claude-haiku-5-5)

A local model works too: DASHBOARD_AI_PROVIDER=openai-compatible, DASHBOARD_AI_BASE_URL=http://localhost:11434/v1 (Ollama) and DASHBOARD_AI_MODEL.

You see the exact request before anything is sent. It is built from what this page shows, redacted: SQL fingerprints, route patterns, names and types. Never rows, env values, cookies or tokens. The key is never shown, logged or stored.
